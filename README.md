Privacy Policy: 
Precision Ballistics does not collect, store, or share personal data on external servers. All rifle, cartridge, and session data entered by the user is stored locally on the device. The app may use the device's gyrometer sensor to measure shooting angle; this data is not transmitted anywhere. The app may access your device's location in order to retrieve local atmospheric and weather data relevant to ballistic calculations; this location data is used only for that purpose and is not stored or shared. If a future paid tier is introduced to save data to the cloud, this policy will be updated accordingly.
